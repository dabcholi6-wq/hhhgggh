# SELF+PLUS Bot

ربات تلگرامی بازی شرط‌بندی و سیستم الماس، با پنل مدیریتی و قابلیت دراپ سریع.

## نصب

```bash
npm install
```

## اجرا

```bash
npm start
```

## تنظیمات لازم قبل از اجرا

باز کنید `bot.js` و این مقدار رو تکمیل کنید:

- **`REQUIRED_GROUP_ID`** — آیدی عددی گروه عضویت اجباری (که برای استفاده از منوی
  خصوصی ربات باید کاربر عضوش باشه). چون تلگرام لینک دعوت خصوصی رو مستقیم به آیدی
  عددی تبدیل نمی‌کنه:
  - ربات رو با توکن فعلی به اون گروه اضافه و ادمین کنید
  - یه پیام توی همون گروه بفرستید (مثلاً `/start`)
  - توی کنسول (ترمینالی که `node bot.js` توش اجراست) دنبال خط
    `چت: <یه عدد منفی>` بگردید و همون عدد رو جای `0` توی
    `REQUIRED_GROUP_ID` بذارید (یا با متغیر محیطی `REQUIRED_GROUP_ID` ست کنید)

بازی، موجودی و دراپ سریع دیگه محدود به یه گروه خاص نیستن — ربات هر گروهی که
بهش اضافه بشه رو خودش می‌شناسه (وقتی هر پیامی توی اون گروه دریافت کنه، آیدیش
رو ثبت می‌کنه) و همون‌جا هم بازی/موجودی/کسر کار می‌کنه، هم توی همه‌ی این
گروه‌ها دراپ سریع روزانه می‌فرسته.

## ویژگی‌ها

- بازی شرط‌بندی بین دو کاربر با عکس و متن اختصاصی، شامل کارمزد پلکانی — در هر گروهی
- سیستم الماس: موجودی، انتقال (با کارمزد پلکانی)، چالش روزانه، زیرمجموعه‌گیری، گردونه‌ی شانس
- عضویت اجباری در گروه و کانال قبل از استفاده از منوی خصوصی ربات
- موجودی ثابت و بدون‌تغییر برای مدیرها
- دستور کسر الماس برای مدیرها (ریپلای روی پیام کاربر + `کسر <عدد>`) در هر گروهی
- دراپ سریع روزانه در ساعت تصادفی (۱۶ تا ۲۳ به وقت ایران)، همزمان در همه‌ی گروه‌هایی
  که ربات عضوشونه

## نکته‌ی امنیتی

توکن ربات مستقیم داخل `bot.js` قرار داره. اگر این مخزن را Public می‌کنید،
توکن لو می‌رود. پیشنهاد می‌شود مخزن را Private نگه دارید یا توکن را از طریق
BotFather ریووک/جایگزین کنید.
